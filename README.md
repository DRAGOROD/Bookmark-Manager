Bookmark Manager is a simple web application that allows users to store, view, and delete bookmarks based on selected categories. The application uses the browser’s local storage to persist data, meaning bookmarks remain saved even after refreshing the page.

**⭐Project Link:-** https://dragorod.github.io/Bookmark-Manager/

**🛠️ Toolkits**
HTML5
CSS
JavaScript

**⚙️ Development Process**
Built the HTML structure with three main sections: category selection, add bookmark, view/delete bookmarks
Flexbox for layout
Created a function to safely retrieve bookmarks
Used localStorage to store bookmarks as an array of objects
Implemented dynamic rendering of bookmarks using .map() and .join()
Used event listeners to handle button interactions
Applied filtering logic to display bookmarks by category
Implemented deletion based on selected radio button

**✨ Features**
Add bookmarks with:Name, URL, Category
View bookmarks filtered by category
Delete selected bookmark
Persistent storage using localStorage
UI updates without page reload
Clean toggle-based navigation between sections

HTML rendering with .map() and .join()
